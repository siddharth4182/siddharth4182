**siddh# 🩸 Blood Group Identification Using Fingerprints

A Flask-based AI application that identifies blood groups rapidly from fingerprint images using **Gabor filters, sweat/skin antigen analysis, and Convolutional Neural Networks (CNN)**.

## 🎯 Motivation
Traditional blood-group testing relies on lab equipment, serological reagents, and trained personnel. This project explores a **non-invasive, image-based alternative** — using fingerprint characteristics to predict blood group quickly enough for emergency or field use.

## ✨ Key Features
- Fingerprint image preprocessing (Gabor filtering for ridge/valley detail)
- Feature extraction based on skin & sweat antigen patterns
- **CNN** model for blood-group classification
- Clean **Flask web UI** for upload + real-time prediction

## 🧠 Approach
1. Preprocess raw fingerprint images
2. Apply Gabor filters to extract texture features
3. Train a CNN on labeled fingerprint → blood-group data
4. Serve predictions through a Flask endpoint

## 🛠️ Tech Stack
Python · Flask · OpenCV · TensorFlow/Keras · CNN · Numpy
